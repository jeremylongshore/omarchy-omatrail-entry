# Support

For gameplay defects, save recovery problems, accessibility issues, or Omarchy
compatibility failures, open a GitHub issue with:

- Omarchy and Quickshell versions;
- omaTrail version and replay seed;
- the current game phase and display profile;
- minimal reproduction steps;
- relevant shell log lines with private paths or names removed.

Use private vulnerability reporting for security concerns. omaTrail is a
personal open-source project with best-effort support and no response-time SLA.
